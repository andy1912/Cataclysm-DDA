# Playtest bug reports

This folder holds one markdown file per bug found in the guided playtests: `PT-xx_short-name.md`.
- Checks and their IDs: [../PLAYTEST.md](../PLAYTEST.md).
- Template, naming and severity: [../BUG_REPORT.md](../BUG_REPORT.md).
- Logs and saves for a report: `tools/saigon/collect_bug_report.sh -w "<world>" -t PT-xx`. It writes
  under `~/code/cdda-saigon-logs/bug_reports/` and stays out of git.

Status is one of: **open**, **confirmed**, **in progress** (with the unit ID), **fixed** (with the commit),
**won't fix**, **duplicate of PT-yy**, **known limit**.
