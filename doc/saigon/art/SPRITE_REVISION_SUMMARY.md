## Format rules

| Rule | Detail |
|---|---|
| File type | PNG, RGBA, transparent background, **not interlaced** |
| Size | Exactly the size in the table, matching the original sprite it replaces |
| File name | The tile id, for example `t_brick_wall.png` or `sgn_non_la.png` |
| Vehicle parts | `vp_<part id>.png`, for example `vp_wheel_motorbike.png` |
| Clothing worn on the character | Two images: `overlay_male_worn_<id>.png` and `overlay_female_worn_<id>.png` |
| Seasonal art | `<id>_season_winter.png` and so on. Saigon uses summer art all year. |
| Connecting terrain (walls, sidewalk, road) | All pieces: `center`, `corner`, `edge`, `t_connection`, `end_piece`, `unconnected` (+ `broken`), described in a sidecar `<id>.json` ([`doc/TILESET.md`](../../TILESET.md)) |
| Rotating furniture (fridge, oven, dresser) | 4 facings |
| Licence | CC-BY-SA 3.0. Record the author and source for every sprite ([`STYLE_GUIDE.md`](STYLE_GUIDE.md) §7) |
| Isometric (later) | 64×32 floor diamond, 4 facings, plus normal, height and emissive maps ([`STYLE_GUIDE.md`](STYLE_GUIDE.md) §1). Not needed now. |

**Known limitation:** the hand-art packer (`tools/saigon/art/build_sprites.py`) currently accepts only **32×32** (`art/saigon/tiles32/`) and **16×16** map icons (`art/saigon/overmap16/`). The other sizes (20×20, 32×36, 32×48, 32×64, 96×96) are produced only through derived recipes today. Hand art at those sizes needs one extra `SHEETS` entry per size in that script.

## Already done (derived from the original art, recolours only)
- **Tropical seasons:** all 263 winter and autumn variants use summer art.
- **Walls and fittings:** pastel stucco walls, teal rolling shutters, green doors and window grilles.
- **Ground:** warm sidewalk tiles and cream floor tiles.
- **Furniture:** the red ancestor altar, red plastic stools and a stainless water tank.
- **Zombies:** ward-police (khaki), fevered dead (pale gown), market (orange apron) and xe ôm (red helmet).
- **Outfit:** the nón lá, nón bảo hiểm, bat-wing poncho and dép tổ ong, as item icons plus worn sprites.
- **Map:** icons for nhà ống, hẻm, chợ, chùa and chung cư.
- Previews: [`derived_preview.png`](derived_preview.png), [`derived_overmap_preview.png`](derived_overmap_preview.png).

Recolouring keeps the original shapes. Shape changes, such as a conical nón lá or palm trees, need hand-drawn art.

## Commands (run from the repo root)

| Task | Command |
|---|---|
| List ids still needing art (by tier) | `python3 tools/saigon/art_coverage.py --list T1` |
| Pack hand-drawn PNGs | `python3 tools/saigon/art/build_sprites.py` |
| Re-run the recolour recipes | `python3 tools/saigon/art/derive_sprites.py` |
| Check the packed tilesets | `python3 tools/saigon/art/validate_tileset.py` |
| Regenerate the full list and manifest | `python3 tools/saigon/art_manifest.py` |
| Play (graphics, Saigon preselected) | `./play_saigon.sh`, then create a **new world** |
